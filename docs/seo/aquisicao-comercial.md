# Aquisição comercial da Tironi Tech

A home apresenta software sob medida, automação com IA, integração de sistemas e consultoria de IA. A métrica principal é oportunidade qualificada por serviço e origem. Um clique no WhatsApp indica interesse. A conversa recebida e a qualificação pertencem ao registro comercial.

## Consultas para acompanhar

| Serviço | Consultas de contratação | Página principal |
| --- | --- | --- |
| Software sob medida | empresa de desenvolvimento de software sob medida, orçamento de sistema interno sob medida, empresa para desenvolver portal B2B | `/software-sob-medida` |
| Automação com IA | empresa de automação com IA, contratar automação de processos empresariais, implantação de IA para triagem de documentos | `/automacao-processos-com-ia` |
| Integração de sistemas | empresa de integração ERP e CRM, fornecedor para integrar pedidos entre sistemas, orçamento integração de sistemas via API | `/integracao-de-sistemas` |
| Consultoria de IA | consultoria para implementar IA na empresa, empresa para implantar piloto de IA, consultoria de IA para processos internos | `/consultoria-ia-para-empresas` |

Para buscadores tradicionais, exporte os dados por consulta e página no Search Console. Separe buscas de marca das demais. Use janelas de 28 dias e um acumulado de 90 dias quando houver poucos cliques. Compare as possíveis páginas concorrentes antes de decidir entre diferenciação e redirecionamento.

Para IA generativa, transforme as consultas em perguntas de compra e repita a mesma amostra mensalmente. Registre data, serviço, plataforma, fornecedor e URL mencionados, além da evidência citada. A amostra serve para identificar quais respostas ou provas faltam no site. Use a origem de chegada e o relato do contato para acompanhar oportunidades identificáveis. A presença nas respostas e o volume de leads são métricas distintas.

## Do contato à proposta

- `diagnostic_link_click` indica acesso ao formulário por um CTA.
- `lead_form_start` indica a primeira interação com o formulário.
- `diagnostic_submit` indica resposta de sucesso da API de captação.
- `whatsapp_contact_click` indica clique no link. Registre conversas recebidas manualmente quando não houver integração de atendimento.
- No registro comercial, acompanhe necessidade, serviço, etapa, origem, próximo passo e motivo de perda.
- Os campos `Projeto` e `Origem_CTA` do SendPulse precisam ser verificados em um envio real após a publicação. O briefing fica no registro comercial.

Quando houver um novo case publicável, registre desafio, escopo entregue, resultado observável, período e condições de divulgação. Ligue o case à página de serviço correspondente e procure uma referência externa quando o parceiro ou cliente puder confirmar o trabalho.

A consulta local do Search Console respondeu HTTP 400 durante a auditoria. Use a propriedade da Tironi Tech no painel para exportar dados recentes enquanto a conexão da API é revisada.
